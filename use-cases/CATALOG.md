# SkillVenom use-case catalogue

61 defensive use cases, each a defanged agent-file payload with the SkillVenom rules it should trigger. Generated by `tools/use_cases.py render`, do not edit by hand.

> Every payload is defanged and for testing detection only. Never run one.
