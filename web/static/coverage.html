Evaluation transparency

Evidence before trust

AgentLens reports static signals, not a malware verdict or safety certification. Original submissions are not published in a directory. Sanitized assessments are publicly available through exact snapshot-fingerprint or indexed file-text-hash lookup.

What a score means

The signal risk score runs from 0 to 100. Higher means more distinct rule evidence, not a probability of malware. Each rule contributes only its highest observed severity: CRITICAL 40, HIGH 20, MEDIUM 5, LOW 1. The sum is capped at 100. Repeated matches of one rule do not inflate the score.

Partial scans and scans with no target files are not scored. A complete scan only covers the selected, supported files, not all behavior of a skill or repository. A zero score means no current rules matched, not that the skill is approved.

Compare scores only with the same methodology version, detector fingerprint and scan scope. A changed rule set can change a score without any change to a skill.

Performed

Static pattern analysis and embedded-secret pattern detection, plus bounded recursive base64, UTF-16LE base64, hex and percent decoding. Saved JSON MCP tool definitions are inspected as decoded data with JSON-pointer evidence. Schema and sensitive-input observations are review notes, not scored vulnerabilities. No MCP server is contacted.

Not performed

No sandbox execution, live credential checks, publisher reputation checks, signature verification, remote-content inspection or installed dependency analysis. AgentLens does not execute submitted files.

Content evidence

Reports include the repository commit when available, SHA256 hashes of inspected UTF-8 text, an input-manifest hash and a detector fingerprint. An optional UTF-8 BOM is removed before hashing. These are not signed attestations.

Decoded evidence and interoperable reports

Encoded-text inspection follows up to three layers with shared per-file limits of 128 candidates, 32 payloads and 64 KiB of decoded text. Reaching a limit makes the scan partial and unscored. Findings identify the containing source line or JSON pointer, transformation chain and decoded line; decoded line numbers are not presented as physical source lines.

Export SARIF 2.1.0 from the report for code-scanning tools. The browser builds the export locally, excluding snippets and original content. It retains evidence locations, fingerprints and incomplete-scan status, without inventing CVSS scores. Review paths, pointers and other metadata before publishing.

Counting content, not claiming trust

A skill snapshot groups inspected files under a SKILL.md folder. Its content ID binds package-relative paths, raw-byte hashes and file modes where known. An evaluation ID also binds the detector, options and completeness; finding IDs bind evidence locations within that evaluation. Matching copies with equivalent metadata count once, while content edits create new versions. Unknown file modes are not treated as known modes.

Only eligible pinned GitHub packages with every listed file inspected can count as complete supported versions. Uploads and other repository providers remain snapshots. Missing files, unsupported assets, nested skills and partial scans prevent complete-parent claims. This is not exhaustive dependency resolution, signature verification or proof of safe behavior.

All scans, including private-token scans, automatically register digest identities and sanitized assessment summaries indefinitely. Central fingerprint search publishes the latest stored assessment by exact content ID, including private-scan fingerprints. Summaries omit paths, repository URLs, snippets and originals. Knowing a content fingerprint can reveal that private content was scanned. High-risk originals are retained privately for 30 days, separately from public summaries. Tokens are never retained. Security findings count distinct finding fingerprints, not repeat scan hits. Public counts are cached shard snapshots, not unique people, publishers or adoption figures. Storage is bounded and errors are disclosed.
