Fingerprint search

Look up an exact skill, MCP or agent-file snapshot and its latest stored assessment. No account or current browser-tab scan is required.

Paste the linked content fingerprint from any report, or an inspected-text SHA256 from a newly indexed scan. A file-text hash can match several containing snapshots; it is not the snapshot identity. Older file-text hashes need a rescan. Raw-download hashes, evaluation IDs and finding IDs are not search keys. Private-scan fingerprints are discoverable too. Reports omit paths, repository URLs, snippets and originals.
