Fingerprint search

Look up an exact skill, MCP or agent-file snapshot and its latest stored assessment. No account or current browser-tab scan is required.

Metadata lookup only. Search retrieves stored assessment metadata and bounded, redacted finding excerpts. It never downloads the full skill, original files or repository contents, and does not run a new scan. Only snapshots with HIGH or CRITICAL findings are registered.

Paste a snapshot fingerprint or indexed file-text hash. A text hash may match several snapshots; older scans need a rescan. Raw-download hashes, evaluation IDs and finding IDs are not search keys. Qualifying HIGH/CRITICAL snapshots from all sources, including private scans and uploads, publish self-declared names and redacted finding excerpts. Names are not verified identity. Full originals stay private; excerpts can disclose private information despite detected-secret redaction.
