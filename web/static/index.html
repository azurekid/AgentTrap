    How it works

    Three steps, zero trust

    1. 01

      Collect

      Upload files or name a GitHub, GitLab or Azure DevOps repository. SkillVenom lists the commit's file tree and inspects only files an agent would load.

    2. 02

      Inspect

      An isolated scanner applies injection, credential, execution, and exfiltration rules. Nothing is run, rendered, or followed.

    3. 03

      Report

      Every signal is mapped to a file, line or decoded JSON pointer, severity, MITRE ATLAS technique, and research reference. Detected secret values are redacted before they reach your screen.
