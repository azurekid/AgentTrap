      File findings

      How it works

      Three steps, zero trust

      1. 01

        Collect

        Upload files or name a public repository. AgentTrap lists the commit's file tree and fetches only files an agent would load.

      2. 02

        Inspect

        An isolated scanner applies injection, credential, execution, and exfiltration rules. Nothing is run, rendered, or followed.

      3. 03

        Report

        Every signal is mapped to a file, line, severity, MITRE ATLAS technique, and research reference. Secrets are redacted before they reach your screen.

      Detection coverage

      Beyond the Markdown

      Inspect instructions, configuration, and the permissions between them.

      Prompt injection

      Instruction overrides, fake system tags, hidden comments, and invisible Unicode that redirect agent behavior.

      Exposed credentials

      Cloud, AI-provider, GitHub, and npm tokens, private keys, and credentialed URLs — redacted in every report.

      Unsafe execution

      Pipe-to-shell installs, risky hooks, MCP servers, auto-approval, and workspace tasks that run on open.

      Data exfiltration

      Instructions that ship files, environment variables, or credentials to external endpoints, DNS, or images.

      Mapped to MITRE ATLAS

      Every finding is linked to ATLAS tactics and techniques, with the ATLAS mitigations that address it — from LLM Prompt Injection to Modify AI Agent Configuration.
